# Contributing

Thanks for helping improve Nebula Survivors V2.

## Development
1. Clone the repository.
2. Open `index.html` through a local static server (recommended) or use Netlify.
3. Keep gameplay code in `js/`, styling in `styles/`, and static assets in `assets/`.
4. Test desktop keyboard controls and mobile pointer controls before opening a PR.

## Code style
- Use modern browser JavaScript.
- Prefer small focused functions.
- Avoid frameworks unless the project direction explicitly changes.
- Keep game state deterministic where practical and avoid unnecessary allocations inside the frame loop.

## Pull requests
Describe what changed, how you tested it, and any gameplay/balance effects.
